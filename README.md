# Sudha-s-Kitchen-Front-End-Application
Sudha's Kitchen is a responsive restaurant frontend web application developed using React.js. The application showcases authentic Andhra and Rayalaseema cuisine, allowing customers to explore dishes, view prices, search the menu, add items to a shopping cart, manage favourites, and submit reservation and contact forms. 

🎯 **Project Objectives**

Build a responsive restaurant website using React.js.
Display restaurant information, food items, prices, and descriptions.
Implement navigation between multiple pages using React Router.
Manage application state using React Hooks, Context API, and Redux Toolkit.
Implement menu search, category filters, favourites, and cart functionality.
Demonstrate CRUD operations and API data fetching.
Create user-friendly reservation and contact forms.

✨ **Features**
Home Page: Restaurant introduction and featured dishes.
About Us: Restaurant information and background.
Menu Page: Browse food items with prices, images, search, and category filters.
Dish Details: View individual dish information using dynamic routing.
Shopping Cart: Add and manage selected food items.
Favourites: Save and view favourite dishes using Redux Toolkit.
Reservation Form: Enter customer details and reservation information.
Contact Page: Display restaurant contact details and provide a contact form.
Services Page: Explore restaurant services with nested routing.
Customer Directory: Fetch and display customer information using Axios.
Menu Management: Add, edit, and delete menu items.
Responsive Design: Supports desktop, tablet, and mobile screens.
